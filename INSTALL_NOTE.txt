IMPORTANT iPhone installation:
This package is an Xcode iPhone project. A Mac with Xcode is required to build/sign it into an installable IPA using the normal Apple toolchain.

The project was not built here because this environment has no Mac/Xcode.

Free/no-paid-Developer route after an IPA is available:
A Windows PC can use a free Apple-ID signing/sideload route such as AltStore/AltServer, subject to Apple's current signing limits. This still requires an IPA first; this source ZIP alone cannot be installed directly on an iPhone.

No Apple Developer Program payment is included or required for this source handover.
